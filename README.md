This project implements an interactive Python-based deal scenario analysis tool designed to evaluate whether a hypothetical acquisition is accretive or dilutive to an acquiring company’s earnings per share. The model mirrors the structure and logic used in investment banking and corporate development to screen potential transactions by combining real public financial data with user-defined assumptions and testing outcomes across multiple scenarios.
When executed, the program first pulls factual market and financial data for both the acquirer and the target using publicly available sources. This includes each company’s current share price, shares outstanding, and most recent annual net income. These values form the baseline inputs of the model and are intentionally automated to separate objective data from subjective deal assumptions. This distinction reflects real-world practice, where analysts rely on market data as fixed inputs while management and deal teams debate assumptions.
After retrieving the financial data, the program prompts the user to enter key deal parameters. These include the acquisition premium paid above the target’s market value, the mix of cash, stock, and debt used to finance the transaction, the acquirer’s tax rate, the interest rate on incremental debt, expected annual synergies, and integration-related costs. Each of these inputs directly affects the pro forma earnings calculation and represents judgment rather than fact. Defaults are provided to allow quick evaluation, while user input enables sensitivity analysis without modifying the underlying code.
Using these inputs, the model constructs a simplified pro forma earnings profile. It combines the acquirer’s and target’s standalone net income, adds after-tax synergies, subtracts after-tax interest expense and amortization, and adjusts for dilution caused by newly issued shares. The resulting pro forma net income is divided by the updated share count to compute pro forma EPS. This value is then compared to the acquirer’s standalone EPS to calculate accretion or dilution.
To reflect uncertainty and execution risk, the model automatically evaluates three scenarios: a base case representing expected performance, an upside case assuming stronger synergy realization and lower financing costs, and a downside case reflecting weaker execution and higher costs. For each scenario, the model reports accretion or dilution and flags transactions that exceed a predefined dilution threshold. This approach mirrors how deal teams stress test transactions to understand what conditions cause a deal to fail.
The output is intentionally structured to support interpretation rather than optimization. Large dilution typically indicates excessive stock issuance, high leverage, or a target that is too large relative to the acquirer. Conversely, modest accretion often reflects either meaningful synergies or a conservative financing structure. Importantly, a deal that fails in the downside scenario is not considered a modeling error but a substantive conclusion, indicating that the transaction may be structurally unsound.
While the model simplifies certain accounting elements and does not replace a full multi-year valuation, it effectively demonstrates how acquisition economics respond to changes in price, financing, and execution assumptions. The primary goal is not to predict transactions but to evaluate feasibility and risk in a disciplined, repeatable way. By separating data from judgment and emphasizing scenario analysis, the tool replicates the analytical mindset used in professional deal evaluation and provides a practical framework for understanding how mergers and acquisitions impact shareholder value.
